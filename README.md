## Descripción

**Glóbulo-0** es un **bullet hell + roguelike 2D pixel art** donde controlas a un glóbulo blanco defendiendo al cuerpo humano de amenazas inspiradas en el **virus de la gripe**.  
Cada run está pensada para ser intensa, rejugable y centrada en habilidad: esquivar patrones, optimizar mejoras y sobrevivir a oleadas cada vez más complejas.

---

## Características principales

- Combate **bullet hell** con patrones de proyectiles y movilidad precisa.
- Estructura **roguelike** basada en runs y progresión.
- Estilo **pixel art** con identidad visual propia.
- Dificultad enfocada en aprendizaje y dominio del jugador.
- Temática inspirada en el sistema inmunológico.

---

## Arte y audio

- **Entornos, paredes, decoración y algunos enemigos:** assets gratuitos de **Craftpix.net**.
- **Suelo, jugador, balas, UI y otros elementos clave:** creados por mí en **Aseprite**.
- **SFX:** combinación de sonidos generados con **IA (Suno)** y recursos adicionales de **Pixabay**.
